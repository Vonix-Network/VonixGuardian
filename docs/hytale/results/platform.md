## Mapping

Hytale has no 0–4 op level. `HytaleOpLookup` returns 4 when `PlayerRef.hasPermission("*")` (online) or `PermissionsModule.hasPermission(uuid, "*")` (otherwise) is true, and 0 otherwise. `"*"` is `PermissionsModule.ROOT` and the only builtin permission on `HytalePermissionsProvider.OP_GROUP` (`hytale:Admin`).

`HytaleConfigLoader` writes defaults only when `config.json` is absent, and fails the load when an existing file cannot be read, parsed, or validated. Log lines contain the path and the exception class name.

`HytaleExecutors.writerThreadFactory` creates daemon threads named `VonixGuardian-Writer`. `serverThread(World)` lands on that world's queue via `World.execute`.
